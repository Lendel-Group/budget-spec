# 06. Различия платформ

| | PWA (web, iOS) | Android (Kotlin) |
|---|---|---|
| Репозиторий | `al-writer/PWA-Budget` | `al-writer/android-budget` |
| Хранилище | IndexedDB (Dexie) | Room (SQLite) или аналог |
| Распространение | GitHub Pages, установка «на экран Домой» | Google Play (пакет `app.lendel.mbt`) |
| Обновления | Service worker + баннер «Обновить» | Google Play (in-app updates — по желанию) |

## Что общее (обязательно одинаково)
Всё из [01](01-data-model.md)–[05](05-screens.md): модель, расчёты (фикстуры), операции, формат бэкапа, экраны и тексты.

## Что только в PWA (в Android не переносить)
- **Предложение установки** на главной («Установите приложение», подсказка для iOS Safari, откладывается на 14 дней)
  и кнопка «Установить приложение» в «О приложении».
- **Баннер обновления** service worker и кнопка «Проверить обновления».
- **Защита хранилища** (`navigator.storage.persist`, экран «Резервные копии» после «Вручную»): строка «Хранилище защищено от очистки» / «может быть очищено»,
  «Занято X МБ из Y МБ», «Запросить защиту». На Android данные приложения не очищаются системой — секция не нужна
  (можно показывать занятый объём, по желанию).
- **Лендинг** и **инструкция** — страницы сайта. Android даёт ссылку на ту же инструкцию в «О приложении».
- Строки диагностики «Режим», «Экран», «Окно при запуске» в «О приложении».

## Что только в Android

### Блокировка приложения
Защита от посторонних, у которых в руках разблокированный телефон. Это не шифрование данных: от доступа к файлам
устройства защищает шифрование самого телефона.

- **Чем разблокировать** — системный замок экрана телефона: отпечаток, лицо или код телефона (системное окно,
  `BiometricPrompt` с разрешённым кодом устройства). Своего пин-кода у приложения нет: аккаунта нет, и забытый код
  нечем было бы восстановить.
- **«Настройки» → «Безопасность»** (группа «Приложение», сразу после «Оформления»; сводка в строке — «Выключена» |
  «Включена · Сразу» | «Включена · Через 1 минуту» | «Включена · Через 5 минут», без замка экрана телефона —
  «Нужна блокировка экрана»). Экран «Безопасность»:
  - переключатель «Блокировка приложения», подпись «Отпечаток, лицо или код телефона при входе»; по умолчанию выключен;
  - «Запрашивать» — «Сразу» | «Через 1 минуту» | «Через 5 минут» после выхода из приложения (по умолчанию «Сразу»);
    виден, только когда блокировка включена;
  - если на телефоне не настроена блокировка экрана, переключатель недоступен с подписью «Чтобы включить, настройте
    блокировку экрана в настройках телефона.»
  - включение требует успешной проверки в системном окне (так пользователь убеждается, что разблокировка работает);
    выключение — нет: приложение в этот момент уже открыто.
- **Когда запрашивать**: при каждом запуске приложения и при возврате в него, если с момента ухода прошло не меньше
  выбранной задержки («Сразу» — при каждом возврате). Выбор файла (резервная копия, автобэкап) и системное окно
  разблокировки уходом не считаются.
- **Экран блокировки**: вместо содержимого — название «MBT», текст «Приложение заблокировано» и кнопка
  «Разблокировать»; системное окно с заголовком «Вход в MBT» открывается само. Отмена в окне оставляет экран
  блокировки. Нижняя панель и «+» на экране блокировки недоступны.
- **Список недавних приложений**: пока блокировка включена, снимок экрана приложения в нём скрыт.
- Если замок экрана телефона потом убрали, проверка невозможна — приложение открывается без неё, а переключатель
  в «Безопасности» показывает подпись о настройке блокировки экрана.
- Хранится локально (spec/01): не в config и не в бэкапе; восстановление из файла и полный сброс её не меняют.

PWA блокировки нет: без сервера проверка в браузере остаётся только «шторкой» (WebAuthn можно обойти через
инструменты разработчика).

## Как реализовать платформенные функции на Android

### Автобэкап в файл
- PWA: File System Access API (только Chromium), пользователь выбирает файл, после перезапуска браузера доступ нужно
  подтвердить («Автобэкап приостановлен · Возобновить»).
- Android: Storage Access Framework — `ACTION_CREATE_DOCUMENT` (имя по умолчанию `budget-backup-YYYY-MM-DD.json`,
  тип `application/json`) + `takePersistableUriPermission`. URI хранится в локальных настройках (не в бэкапе).
  Запись — та же задержка 1,5 с после последнего изменения данных, в фоне (корутина / WorkManager).
  Если доступ к файлу потерян — то же состояние «Автобэкап приостановлен», предложить выбрать файл заново.
- Тексты статусов те же: «Автобэкап не настроен.», «Автобэкап активен: каждое изменение сохраняется в файл.»,
  «Автобэкап приостановлен — нужно подтвердить доступ к файлу.», кнопки «Привязать файл автобэкапа» /
  «Выбрать другой файл автобэкапа».
- Полный сброс отвязывает файл автобэкапа (как в PWA).
- Дополнительно можно включить системный Android Auto Backup (`android:allowBackup`) — это не заменяет файл,
  а дополняет его.

### Скачать резервную копию / восстановить
- Android: «Скачать резервную копию JSON» — `ACTION_CREATE_DOCUMENT`; «Восстановить из файла» — `ACTION_OPEN_DOCUMENT`
  (`application/json`). Формат и проверки — [04](04-backup-format.md).

### Тема
- PWA: выбор в `localStorage` (`theme`); до отрисовки приложения скрипт в `index.html` ставит на `<html>` атрибут
  `data-theme` (`light` | `dark`) по выбору или `prefers-color-scheme` и `color-scheme`; при «Как в системе» —
  подписка на изменение `prefers-color-scheme`. `<meta name="theme-color">` — цвет surface текущей темы.
- Android: выбор в локальных настройках (SharedPreferences, читаются синхронно до `setContent`); при «Как в системе» —
  `isSystemInDarkTheme()`. Системные панели — `enableEdgeToEdge` со стилем по теме приложения, а не системы
  (`SystemBarStyle.dark` / `light` с прозрачным фоном): иначе при светлой системе и тёмной теме приложения значки
  строки состояния не видны.

### Дата «сегодня»
Локальная дата устройства; пересчитывать при возврате в приложение и после полуночи (как `useToday` в PWA).

### Сеть
Единственный запрос — курсы ([03](03-operations.md#курсы-валют)). Разрешение `INTERNET`; никакой аналитики,
рекламы и сторонних SDK, отправляющих данные.

### Форматирование чисел
Не полагаться на `NumberFormat` Android/ICU «как есть»: сверять со строками в `fixtures/format.json`
(разделитель тысяч U+00A0, минус `-`, «копейки только если есть»). Проще реализовать форматирование вручную.

### Иконки
Набор Lucide (ключи — [05](05-screens.md#иконки)).

## Политика конфиденциальности (для Google Play)
Данные только на устройстве, аккаунта и сервера нет, единственный внешний запрос — файл курсов валют с
`al-writer.github.io`. Анкета Data Safety: «данные не собираются и не передаются».
