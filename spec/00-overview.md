# 00. О продукте

**My Budget 2026** — офлайн-приложение для учёта личных финансов: счета, операции, помесячный бюджет,
долги, цели, дни без трат и годовая аналитика.

## Принципы (не нарушать ни на одной платформе)
1. **Local-first, без сервера.** Все данные — только на устройстве. Нет аккаунтов, синхронизации, аналитики, рекламы.
   Единственный сетевой запрос — файл курсов валют; без сети всё работает.
2. **Деньги в тенге.** Базовая валюта KZT; счета могут быть в USD, EUR, RUB, итоги пересчитываются в тенге
   по текущим курсам. Долги и цели — только в тенге.
3. **Быстрый ввод.** Операция добавляется за пару нажатий: кнопка «+» с любого экрана, своя цифровая клавиатура,
   частые категории первыми, счёт последней операции по умолчанию.
4. **Данные не теряются.** Каждое изменение атомарно; есть ручной экспорт, автобэкап в файл, восстановление
   с подтверждением словом. Удаление операции можно отменить.
5. **Один формат данных на все платформы.** Файл бэкапа одной платформы открывается на другой.
6. **Доступность.** Крупные цели нажатия, подписи для скринридера, состояния не только цветом, крупный шрифт.

## Платформы
| Платформа | Реализация |
|---|---|
| Web, iOS | PWA — `al-writer/PWA-Budget` (эталонная реализация) |
| Android | нативное приложение на Kotlin — отдельный репозиторий |

## Словарь
| Термин | Значение |
|---|---|
| Операция | Расход, доход или перевод между счетами. |
| Лимит | Плановая сумма расходов по категории на месяц. План месяца — сумма лимитов. |
| Лимит на сегодня | Сколько можно тратить в день до конца месяца, чтобы уложиться в план. |
| День без трат | День без расходов, кроме исключённых (коммуналка, кредит, аренда, платежи по долгам, пополнения целей). |
| Серия | Сколько дней подряд (включая сегодня) без трат. |
| Капитал | Сумма балансов активных счетов в тенге. |
| Пополнение цели | Перевод денег со счёта «в цель»: уменьшает баланс, но считается сбережением, а не тратой. |
| Скрытая категория | Не предлагается при вводе, но остаётся в истории, бюджете и аналитике. |
| Архивный счёт | Не предлагается при вводе и не входит в капитал, история сохраняется. |
